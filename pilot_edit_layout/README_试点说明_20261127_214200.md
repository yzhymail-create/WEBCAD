## 已定规则（用户 2026-11-27 逐条确认）
1. 长度是线段的属性参数（len_3d），不是 1:1 几何量；2D 图只是图示。拖动只改图示坐标，长度/节点名/零件号等属性按 ID 绑在节点与线段上自动跟随，值不变。
2. 拖动节点时，相连线段拉直为节点到节点直连（去掉中间折点）；未拖到的保持原样；撤销恢复折线。
3. 长度标注自动跟随，在线段中间、平行于线段（可读方向）；偏移到线的一侧贴近线（7px，净空约 3px），不压线。
4. 调整时标签按用户在下拉里的选择显示（连接器名/扎带名/节点名/长度四开关），未勾的不显示；改勾选即时生效。
5. 调整时不弹浮窗（节点信息框/详情弹窗），退出调整恢复弹窗。
6. 放大缩小四种：滚轮、双击、双指捏合、全图按钮；只看与调整模式都可用。
7. 调整改双击选中：双击节点选中（红环）后才能拖，点别处取消选中；未选中时滑动只平移图面，避免手机误拖；双击空白仍放大。
8. 文字避线：长度字偏到字身一侧；节点名在 8 个方位里按到相连线的最小距离打分选最远；字宽用 canvas 真实测量（按 pretext 核心办法自实现，未引入原库），打分包围盒 ×1.08+1px 余量。复查压线 0。
9. 保存/导入 layout.json（meta.display_layout="schematic"）；改后 layout 可被 make_dxf.py 读入出 DXF（回读全过）。
10. 网格吸附可选（5/10/20/50mm，默认关）；撤销上限 50 步（Ctrl+Z），无重做。
